# Aha's Mischief Maker

An auxiliary library for fuzzing, inspired by [Aha](https://honkai-star-rail.fandom.com/wiki/Aha), the Aeon of Elation. It creates delightful mischief to uncover surprising outcomes, bringing you the joy of discovery.

If you need enable openssl feature, you should install `pkg-config` and `libssl-dev`.
